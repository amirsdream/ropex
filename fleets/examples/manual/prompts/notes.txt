Add a small notes module to this TypeScript repo.

src/notes.ts exports createNotes(). The return value has two methods:
- add(text: string): void. Ignore text that is empty or only spaces.
- list(): string[]. Return the kept notes in the order they were added.

src/notes.check.ts imports createNotes from "./notes.js". It throws an Error unless a fresh store lists [], and unless add("a"), add("  "), and add("b") then list as ["a", "b"].
